## Changes and validation


For Pixel 7a and Galaxy S25, use **TorBridge-Android-1.2.10-arm64.apk** (42.4 MB).
Install over the existing app; do not uninstall first.

TorBridge previously displayed "file already exists" for Android error 1008.
That error actually means Android cannot resume an interrupted transfer; actual
file conflicts use 1009. The incorrect mapping also blocked automatic source
recovery. This release fixes both the message and recovery behavior, including
the saved misleading messages from older versions.

- Retry retires the old Android job and starts a fresh transfer.
- Source refresh cannot hold Retry indefinitely; slow addon lookups have a
  30-second limit, and link preparation/API calls have timeouts.
- Download cards explain Android network, Wi-Fi, and retry waits.
- Cancelling during preparation prevents late responses from starting a download.
- Failed deletions keep their app records and report the failure. Deletion also
  follows a saved file move when Flutter still holds its original path.
- Completed videos keep the library retention protection introduced in 1.2.9.

After updating, retry one affected video while online and test playback before
retrying the rest. Previously deleted video bytes still need a new download.

Validation: clean static analysis, 56 passing host tests and 3 passing native
Android API 36 integration tests. A deliberately interrupted HTTP response
reproduces real Android reason 1008; cancellation, redownload, deletion, and
another same-name download then succeed. Physical Pixel network reliability and
video decoding remain unverified.

Both APKs have version code 13 and the same signing certificate as 1.2.9.

## Additional known issues

The [application audit completed after publication](https://github.com/QuintonD/torbridge/blob/main/docs/application-audit-2026-09-10.md)
reproduced additional issues in episode selection, Windows concurrent downloads,
state recovery, cancellation, history, search, and metadata parsing. They are
documented with priorities and reproduction steps and remain unfixed in 1.2.10.
The APKs attached to this release have not been replaced.
