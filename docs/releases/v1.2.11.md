**Android:** install the APK over TorBridge and choose Update. Do not uninstall
or clear app storage. Both APKs use version code **14**, application ID
`app.torbridge.torbridge`, and the existing signing certificate. The APK is both
installer and update file.

**Windows:** close TorBridge, extract the entire ZIP into a new folder, and run
`torbridge.exe`. Keep its DLLs and `data` folder together. Settings and downloaded
media remain outside the application bundle. Developer-built updates can also
use the repaired update script, which retains an installation backup.

## Fixed

This release addresses every issue group and additional inspection finding in
the [September application audit](https://github.com/QuintonD/torbridge/blob/main/docs/application-audit-2026-09-10.md):

- **Wrong season-pack episodes:** initial and recovery downloads verify the
  requested episode against the filename, even when the source's index is wrong.
- **Concurrent Windows downloads:** same-name transfers have separate reserved
  directories so they cannot overwrite each other.
- **Saved-state recovery:** malformed settings no longer hide valid downloads.
  Unreadable sections are backed up, unreadable download lists are protected from
  replacement, and individual malformed records remain preserved.
- **Cancellation races:** cancel/delete use the latest native job ID and account
  for an enqueue still in flight. Failed removal keeps the record visible.
- **Watched history:** completing playback records history locally even without
  Trakt or if its request fails. Library retains movie/episode metadata independently
  of local files, including after restarting the app and importing Trakt history.
- **Trakt consistency:** watched/unwatched actions target the supplied ID and
  correct endpoint, in order. Explicit local choices take precedence over remote
  snapshots. Authorization polls run one at a time, slow down when requested,
  expire locally, and use bounded network requests. Watched sync follows all pages,
  including short pages returned by the service.
- **Search and source labels:** late searches cannot overwrite newer or cleared
  queries; Not cached, GiB/MiB sizes, and HDR10+ parse correctly.
- **Diagnostics and player text:** explicit check severity replaces text guessing;
  audio/subtitle separators and Trakt playback explanations are consistent.
- **Release tooling:** current versioned Windows bundles include all plugin files;
  native build exit codes determine success even when a plugin prints a warning.

The interrupted Android download fixes from 1.2.10 remain included. After updating,
run Diagnostics, retry one affected video while online, and confirm playback.
Video bytes already deleted from the device require a new download.

## Validation

- Flutter static analysis: clean.
- Host regression suite: **79 passing tests**, including all eleven original audit
  probes and added state, race, Trakt, parser, and persistence cases.
- Android API **36** emulator: **3 passing native integration tests** covering real
  Download Manager interruption/retry, deletion/re-download, file/content byte
  ranges, and background completion retention.
- The signed universal release APK installed successfully over the existing
  emulator application and reports version 1.2.11/code 14.
- Windows packaging fixtures: complete plugin/asset replacement, original bundle
  backup, dynamic version, unsafe-path rejection, stderr handling, and failure exit
  codes. All **32 ZIP entries** match their release build bytes.

No physical Pixel 7a or live Trakt account was available for validation. Provider
network reliability and codec compatibility are not guaranteed by the fixture
and emulator tests. Earlier published releases have not been replaced.
